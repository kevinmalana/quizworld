# Live-game vocabulary

This glossary covers live quizzes, not self-paced study or live presentations.

- **Quiz**: an ordered collection of questions used to create a game.
- **Game**: one running competition using a fixed quiz and game mode.
- **PIN**: the short join code for a game; not an enduring game identity.
- **Game instance**: a particular occurrence of a game, distinct from other games that reuse its PIN.
- **Host**: the person authorized to start, reveal and advance a game and view its detailed results.
- **Player**: a participant with a nickname, answers and a score within one game.
- **Host-player**: one person acting as both host and player, with both responsibilities. Hosting alone does not create a player.
- **Spectator**: a viewer without host authority or a player identity.
- **Round**: the answering and reveal phases for one question.
- **Answer window**: the period during which an eligible player may lock an answer.
- **Locked answer**: the player's first accepted answer to a question; it cannot be replaced.
- **Reveal**: closing the answer window, showing the answer distribution and settling that round's scores.
- **Poll**: an unscored question collecting votes, without correct or incorrect responses.
- **Eligible player**: a player allowed to answer; survival excludes already-eliminated players.
- **Ready**: a player's lobby readiness signal, not a prerequisite imposed by the game rules for starting.
- **Finished game**: a game with no further rounds; finishing and durable availability of its report are distinct outcomes.
- **Reconnect**: returning to an existing game identity, not joining as an additional player.
- **Snapshot**: a view of a game's current state, scoped to the viewer's role.
- **Uncertain command outcome**: the caller did not receive a conclusive response; it does not mean the command was rejected or cancelled.
