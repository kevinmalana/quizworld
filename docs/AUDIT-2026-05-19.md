## Critical Gaps

### 1. **Game Page (`/game/[pin]`) — 28 console.error calls**

**Issue:** Excessive console.error means errors are logged but not surfaced to users

**Locations:**
- Error loading players (line 239)
- Error loading answers (line 257)
- Error revealing question (line 323)
- Error starting game (line 648)
- Error advancing game (line 705)
- Error submitting answer (line 781)

**Fix:** Add user-facing error messages with retry options

### 2. **Classroom/[id] — No real-time presence**

**Issue:** Teacher dashboard doesn't show live player activity in classrooms

**Impact:** Teachers can't see who's online while assigning quizzes

**Fix:** Should use Phoenix Presence for classroom membership awareness

### 3. **Groups/[id] — No real-time updates**

**Issue:** Group pages show static data, no live updates when members join/leave

**Impact:** Stale data, requires manual refresh

**Fix:** Add Phoenix channel for group updates

### 4. **Study/[id] — Missing Phoenix integration**

**Issue:** Study sessions are purely Supabase-based, no WebSocket for collaborative study

**Impact:** Can't do "study together" features

**Status:** By design (individual study mode) — but limits future features

### 5. **Present/[code]/live — Different code path**

**Issue:** Presentations use `Presentations` Phoenix module, Games use `Game` module

**Risk:** Inconsistent state management patterns

**Recommendation:** Unified session abstraction?

## Potential Bugs

### 1. **Error Handling Gaps**

28 console.error calls across app with no user feedback:
- `app/game/[pin]/page.tsx` — 6 errors
- `app/dashboard/page.tsx` — 6 errors
- `app/study/[id]/page.tsx` — 5 errors
- `app/join/page.tsx` — 1 error
- `app/study/page.tsx` — 2 errors

**Risk:** Users see silent failures, may think app is frozen

### 2. **XP/Streak Updates Not Atomic**

In `app/study/[id]/page.tsx`:
```typescript
// Lines 114, 125, 130, 140
// 4 separate Supabase calls for:
// - study_progress
// - study_sessions
// - profiles.total_xp
// - profiles.study_streak
```

**Risk:** Partial updates on failure, inconsistent state

**Fix:** Use Supabase RPC function for atomic study completion

### 3. **Leaderboard Weekly XP**

Leaderboard uses `leaderboard_weekly` view but also queries `profiles.total_xp`

**Potential issue:** Weekly XP might not sync with total XP

**Verify:** Check materialized view refresh schedule

## Recommendations

### P0 (Critical)
1. Add user-facing error messages for all console.error calls
2. Make XP/streak updates atomic via RPC
3. Add retry buttons for failed game operations

### P1 (High)
1. Add Phoenix Presence to classrooms for live awareness
2. Add Phoenix channels to groups for real-time updates
3. Surface response_time_ms in reports

### P2 (Medium)
1. Add game replay viewer (ResultSync data exists)
2. Add question analytics dashboard
3. Consolidate present/game session patterns

### P3 (Low)
1. Remove or document unused admin permissions
2. Audit present routes for redundancy
3. Add offline graceful degradation
